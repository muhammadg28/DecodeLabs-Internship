PROCESS LOGIC: THE SHIFT

Mono-alphabetic Substitution

En(x) = (x + n)
x = Character Position
n = Key (Shift)
1
Get Character

THE MATH OF THE WRAP

⚠️ THE VULNERABILITY

Why the Caesar Cipher is a lockbox, not a vault.

1. Tiny Key Space (25 keys = Instant Brute Force)

With only 25 possible shift values, an attacker can try every key in seconds.

2. Pattern Preservation (Frequency Analysis)

Letter frequencies remain unchanged. In English, 'E' is most common - even when encrypted, the most frequent character is likely the shifted 'E'.

3. No Authentication

The cipher doesn't verify who encrypted the message, allowing message tampering.
